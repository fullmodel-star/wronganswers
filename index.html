🔑 金鑰完全免費（Gemini Flash 免費額度，學生用不完），只存在本機、不會外傳。不確定怎麼拿？看下方教學 👇
🔒 隱私提醒：按「拍照辨識」時，照片會上傳到 Google 進行辨識（免費方案的內容 Google 可能用於改善服務）。拍照前請遮住姓名／座號等個資；不想上傳可改用「手動輸入」。其餘功能全部離線。
📖 怎麼取得 Gemini 金鑰？（5 步驟）
1
用瀏覽器打開 aistudio.google.com/apikey，以 Google 帳號登入（Gmail 就可以）。
2
按藍色的 Create API key（中文：建立 API 金鑰）；若問專案，選推薦的或建新專案。
3
複製出現的金鑰，長這樣：AIzaSyD…（一長串英數字約 39 碼）。
4
回到這頁，長按貼上到上方「API 金鑰」欄；模型維持預設 gemini-2.5-flash。
5
按 🔌 測試連線，看到 ✅ 連線成功就完成！之後按 ＋ 拍照就能自動辨識。
🔒 安全：金鑰等於你 Google 帳號的鑰匙，別貼到群組或公開網頁；萬一外流，回 AI Studio 刪掉重建一把即可。
❓ 沒金鑰也能用：可純手動輸入題目，一樣能分類、搜尋、複習。
