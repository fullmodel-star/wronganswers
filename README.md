# 錯題管理器 wronganswers

學測全科（國文／英文／數學／自然／社會）錯題管理 PWA。

## 功能
- 📷 **拍照辨識**：Google Gemini 自動辨識題目、分類、生成解析（含圖形判讀）
- 🗂️ **分類歸檔**：AI 自動歸類科目／章節／題型，可手動調整；支援「按章節分組」檢視
- 🔍 **全文搜尋**：題目、解析、標籤
- 🔥 **間隔複習**：遮答案自測，連對 3 次畢業（精熟；`GRAD_STREAK=3`，畢業後再 14／30／60 天回訪）
- 📊 **統計分析**：各科分布、錯因分析、精熟進度
- 💾 **離線可用**：資料存本機 IndexedDB，可匯出／匯入備份

## 使用
1. 開啟 App → 設定 → 貼上 [Google AI Studio](https://aistudio.google.com/apikey) 的免費 API 金鑰
2. 按 ＋ 拍照 → AI 辨識 → 確認存檔
3. 到「複習」分頁自我測驗

> 金鑰只存本機，不外傳。只有拍照辨識需連網，其餘全離線。

## 自動化測試（2026-10-03 建立）

- `node _tools/ui_tests.mjs`：headless Chrome 瀏覽器走查 72 項，不連外網、不動 App 檔；`--dir=<路徑>` 可對副本或部署包跑。
- 涵蓋新增錯題、遮答案自測、連對 3 次畢業、IndexedDB 存取、首訪不自己重整等；反向測試 8 條。
